## Cách dựng lại / sửa tiếp bằng bất kỳ tài khoản Muse nào

1. Tải file `ung-dung-hoc-toan-lop-1-cho-minh-chau.html` trong repo này về.
2. Mở Muse bằng tài khoản của bạn, tải file đó lên cuộc trò chuyện.
3. Gửi yêu cầu: **"Hãy dựng lại ứng dụng như mã nguồn trong file tôi gửi: tạo một
   ứng dụng web tĩnh (static) và chép NGUYÊN VĂN toàn bộ file HTML này làm trang
   của ứng dụng, không viết lại, không thêm bớt nội dung."**
4. Sau khi dựng xong, cứ yêu cầu Muse ở tài khoản đó sửa / nâng cấp tiếp như bình thường.

không đổi tên/di chuyển — tiến độ học gắn với vị trí file trong trình duyệt.
